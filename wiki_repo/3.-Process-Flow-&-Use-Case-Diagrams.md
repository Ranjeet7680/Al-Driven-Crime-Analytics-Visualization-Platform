## 3. Interactive Copilot & Voice Sequence Flow

```mermaid
sequenceDiagram
    autonumber
    actor Officer as Field Officer / Commander
    participant Mic as Web Speech API (Mic)
    participant Core as Copilot NLP Engine
    participant DB as Karnataka 2025 Dataset
    participant Audio as SpeechSynthesis (Voice)

    Officer->>Mic: Verbal Query ("Which district has highest bike theft?")
    Mic->>Core: Transcribe Speech to Text
    Core->>Core: Parse Intent & Match Entity ("Two-Wheeler Theft")
    Core->>DB: Query 37 Districts for Two-Wheeler Theft
    DB-->>Core: Return Bengaluru City (8,860 cases)
    Core->>Officer: Render Visual Card & Stats on Screen
    Core->>Audio: Synthesize Audible Response (en-IN)
    Audio-->>Officer: Audible Speech Output
```
