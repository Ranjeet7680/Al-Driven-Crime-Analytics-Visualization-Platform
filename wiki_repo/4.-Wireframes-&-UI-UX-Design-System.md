## 3. Design System Tokens & Color Palette

```css
:root {
  /* Brand Accents */
  --purple  : #a855f7;  /* Primary brand & AI accents */
  --blue    : #3b82f6;  /* Operational & dataset highlights */
  --green   : #10b981;  /* Safe status & positive resolution metrics */
  --amber   : #f59e0b;  /* Caution & moderate risk warnings */
  --red     : #ef4444;  /* High danger, critical risk, fatal accidents */
  --cyan    : #06b6d4;  /* HUD accents & fast finder highlights */

  /* Dark Theme (Obsidian) */
  --bg      : #080b14;  /* Background base */
  --bg-card : #111827;  /* Card surface */
  --border  : rgba(255, 255, 255, 0.07);
  --txt     : #f1f5f9;  /* Primary typography */
  --txt2    : #94a3b8;  /* Secondary typography */

  /* Micro-Interactions */
  --ease    : all 0.25s cubic-bezier(0.4, 0, 0.2, 1);
  --blur    : backdrop-filter: blur(16px);
}
```
