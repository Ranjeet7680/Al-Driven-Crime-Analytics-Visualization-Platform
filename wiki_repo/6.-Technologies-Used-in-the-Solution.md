# 🛠️ Technologies Used in the Solution

---

## 📋 Comprehensive Technology Stack

| Layer | Component | Version / Spec | Purpose in Solution |
|---|---|---|---|
| **Core Architecture** | **Vanilla HTML5 & ES6+ JavaScript** | HTML5 / ECMAScript 2023 | Core application structure, routing, controllers, zero-dependency execution. |
| **Styling & Theme** | **Modern CSS3 & Glassmorphism** | CSS3 Level 4 | Glassmorphism, CSS custom properties, responsive grid/flexbox, keyframes. |
| **Data Visualization** | **Chart.js & HTML5 2D Canvas** | v4.4.0 / Canvas API | Bar charts, line graphs, donut visualizers, and interactive geospatial map. |
| **Speech Processing** | **Web Speech API** | W3C Standard | Hands-free speech-to-text (`SpeechRecognition`) and text-to-speech (`speechSynthesis`). |
| **Audio Synthesizer** | **HTML5 Web Audio API** | W3C AudioContext | Native frequency and gain envelope audio oscillator synthesis for tactile UI feedback. |
| **Authentication** | **Firebase Client SDK** | v10.8.0 | User authentication with email/password and Instant Evaluator bypass mode. |
| **CI / CD Pipeline** | **GitHub Actions** | Workflows v4 | Automated syntax testing and continuous deployment to GitHub Pages. |
| **Typography** | **Google Fonts** | Inter, Space Grotesk, JetBrains Mono | Ergonomic headings, clean body UI, and monospaced data metrics. |
