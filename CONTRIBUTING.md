# Contributing to CrimeScope AI 2.0

Thank you for your interest in contributing to **CrimeScope AI 2.0**! We welcome contributions to enhance crime analytics, forecasting models, visualizations, accessibility, and documentation.

## 🤭 Code of Conduct
Please maintain a respectful, welcoming, and collaborative environment. Be constructive in feedback and support open-source policing intelligence innovation.

## 🌿 Git Workflow & Branches
1. Fork the repository on GitHub.
2. Clone your fork locally:
   ```bash
   git clone https://github.com/<your-username>/Al-Driven-Crime-Analytics-Visualization-Platform.git
   ```
3. Create a feature branch:
   ```bash
   git checkout -b feature/awesome-enhancement
   ```
4. Commit changes with clear, semantic commit messages.
   ```bash
   git commit -m "feat: add temporal anomaly detection for cybercrime"
   ```
5. Push to your branch and submit a Pull Request to main.

## 🛹 Issues & Feature Requests
Please use the provided GitHub Issue Templates when reporting bugs or requesting features.
